# 中国站内容管理与预览

中国站复用英文站完整页面模板和国际市场目录，不另做精简版。首页视频、探索轮播、公司介绍、素材与系列、SKU 色卡、案例、新闻正文、下载分组及政策页面均保留。中文未译正文在本地预览中完整显示英文，并有统一草稿提示。

本阶段增加中文编辑、独立中国站设置和本地预览。大陆服务器、备案接入、图片与视频的国内分发属于后续部署工作。

## 编辑流程

1. 在对应文档填写简体中文，包括名称、正文、SEO 和已有的说明、规格标签、下载说明等。新闻正文和素材 FAQ 有独立中文分组。图片、文件、型号、原厂色名与技术数值可复用。
2. 中文状态保持“待完善”即可保存和发布 Sanity 文档。中文不完整不会阻止英文和日文更新。
3. 预览显示英文站完整内容目录，不以初始中文草稿数量筛选。中文接口文案及首批正文已接入；其余英文正文保留全文，需逐项翻译审核。首页、公司介绍和下载中心的中文内容分别在原 Home Page Settings、About Page Settings、Download Page Settings 的简体中文字段编辑。
4. 本地预览读取 Sanity 已发布版本。编辑后点击 Sanity 的 Publish，再刷新预览；这里的“中文待完善”是内容审核状态，与 Sanity 自身的未发布草稿不同。
5. 单条内容准备进入正式中国站时，补齐中文必需字段、将中文发布状态改成“审核通过”，再 Publish。Global 市场内容已包含在中国站范围内，无需逐项重复勾选 China。状态校验会指出缺少的中文字段。
6. 在“中国站设置”中审核首页、公司介绍、联系方式、下载中心，并分别调整栏目状态及站点状态。正式页面同时受站点、栏目、中文完整性和市场范围限制。子系列和 SKU 还要求上级素材与系列可见。

中文版 FAQ 如需隐藏，可保留明确的空数组；如果英日文有 FAQ 而中文分组不存在，则视为尚未处理。新闻需要中文引言，已添加的正文小节需要标题和段落。

## 预览与正式站隔离

- `/zh` 预览只在开发模式开放，带有预览提示和 `noindex, nofollow`。
- 临时公网验收可在中国站独立构建和运行时设置 `CHINA_PUBLIC_PREVIEW=1`。该模式显示待审核内容、保持 `noindex, nofollow`，且询盘表单继续关闭；正式发布前必须移除此变量并将 Sanity 发布状态改为“审核通过”。
- 英日正式站不开放 `/zh`。未审核内容不会加入中国站正式页面或 sitemap。
- 后续中国站独立构建设置 `NEXT_PUBLIC_SITE_KEY=china`，对外路径为 `/`、`/materials` 等；`/zh` 是内部路由，正式访问会跳转为不带前缀的路径。
- 中国站 canonical 固定使用 `https://www.camari.com.cn`，语言为 `zh-CN`。不要把现有英日部署的环境变量改成 China。
- 中国站使用系统中文字体，图片暂时复用现有素材或 Sanity URL。本阶段没有配置大陆对象存储、CDN 或视频镜像。

## 询盘表单

本地预览不能发送询盘。正式接入需要审核通过的中国站与联系方式、后台启用表单并填写个人信息使用说明，以及服务端 HTTPS 环境变量 `CHINA_CONTACT_WEBHOOK_URL`。接收端应先部署并验证，再开启表单。界面已有中文输入校验与提交状态；本阶段没有发送测试询盘。

## 初始化与验证

`node scripts/seedChinaPreview.mjs` 只检查；加 `--apply` 才写入。脚本只补充缺失的中文初稿，不批量勾选中国市场，使用修订号保护并保存修改前后备份到 `outputs/china-preview/`。首次写入已完成，重复检查为零修改。

相关测试：`node --test tests/china-preview.test.mjs`。检查覆盖市场和翻译完整性、父子内容可见性、路由隔离、预览 SEO、公司主体分离及中文询盘校验。
