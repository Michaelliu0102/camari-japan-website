# 字体、Logo 与首页资源优化验收记录

日期：2026-09-27。此提交将两轮已批准的优化合并为一个可回退代码版本，基于 b4ffd6f。没有发布网站、修改 Sanity 内容、DNS、Nameserver 或邮箱配置，也没有发送表单/邮件。

## 改动范围

- 保留原字体，改为自托管 WOFF2；日文字体按 Unicode 子集加载，保留来源清单及 OFL 许可证。非中国站使用字体变量，中国站保留原有字体选择。
- 导航 Logo 使用 576×205 透明无损 WebP，白/黑版本约 5 KB；保持显示尺寸与比例，提前请求。
- 首页轮播、品牌图片及共享 CTA 图片使用现有 Sanity 图片变换与响应式 srcset；保留原始素材和编辑裁切，已核对四条本地图片别名对应原图哈希。
- 轮播接近视口时预载当前及相邻图片，只在可见且页面前台时自动推进；不同时下载手机与桌面隐藏分支的图片。
- HLS 播放器按需加载，保留自适应清晰度，最高 1080p；缓冲目标 8 秒、上限目标 12 秒，分片边界可使实际值略超目标。离屏或后台暂停并停止 HLS 加载，返回后恢复。

## 验证结果

源码及全部新增字体/Logo 共 171 个文件与隔离生产构建工作树逐字节一致。[生产构建和内置 TypeScript 检查通过](build.log)；本轮资源文件 ESLint 检查通过。未因仅整理提交而重复耗时性能测试。

字体/Logo 先前验证覆盖 en/ja 首页、关于页、产品页、联系页，共 112 项浏览器断言通过；测试日志保存在本地 outputs/lcp-font-logo-fix-20260927。浏览器实际字体包含自托管 Inter、Playfair 与 Noto Sans JP，未发起 Google Fonts 请求。

资源最终验证：[完整逐项结果](browser-checks.json)。Chromium 模拟视口 en 390×844 DPR2、en 1440×844 DPR1、ja 360×844 DPR1、ja 768×844 DPR1。72 项断言中 71 项通过、1 项失败。四个视口的 68 项资源/交互断言通过，覆盖轮播、加载、自动播放、离屏停止请求、返回恢复与后台暂停。英文手机首次导航 500，重试为 200；该上下文的“无页面错误”检查失败，不能称全部通过。

## 保留的问题与上线边界

- Sanity 运行时读取偶发超时会导致页面 500，未解决；最终环境必须重新核验，评估读取缓存和失败处理。
- iPhone Safari 原生 HLS、Android 真机、慢网络/丢包、最终 CDN 缓存和全站 LCP 未验证。HLS.js 缓冲策略不等于已控制原生 HLS 网络行为。
- 未批量压缩全站产品图片或下载 PDF；本轮聚焦首页和共享 CTA 图片。
- 真实询价发送须另获批准并核实收件。正式域名切换须提交 DNS 变更清单、邮箱核对及回退方案。
